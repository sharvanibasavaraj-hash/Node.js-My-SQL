# Node.js + MySQL

This repository contains my learning and practice programs while exploring backend development using Node.js and MySQL.

## Topics Covered

- Node.js fundamentals
- Modules and `require()`
- Working with MySQL using `mysql2`
- Connecting Node.js to MySQL
- Executing SQL queries from Node.js
- Inserting records into a database
- Retrieving records using SELECT
- Updating records using UPDATE
- Deleting records using DELETE
- Introduction to Express.js
- Creating REST APIs
- Handling GET, POST, PUT and DELETE requests
- Testing APIs using Postman

## Technologies Used

- JavaScript
- Node.js
- Express.js
- MySQL
- MySQL Workbench
- Postman

## Purpose

The purpose of this repository is to document my practical learning of Node.js and SQL and build a foundation for backend development.
